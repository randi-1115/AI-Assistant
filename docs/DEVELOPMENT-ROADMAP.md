# 开发阶段与验收清单

遵循“每阶段都可运行、每阶段都能解释”的路线。不要先铺满所有空文件再实现业务。

## 阶段 0：开发环境与骨架

**实现**：Git 仓库、Vue/Vite 页面壳、FastAPI `GET /health`、配置加载、MySQL 连接、Alembic 初始化、README。

**验收**：前后端能分别启动；后端 health endpoint 返回正常；MySQL 连接成功；密钥不会出现在前端 bundle 或 Git 仓库。

**学习**：虚拟环境、npm、HTTP/JSON、FastAPI 路由、Pydantic 配置、环境变量、MySQL 用户与数据库。

## 阶段 1：聊天与会话历史

**实现**：会话 CRUD、消息持久化、上下文组装、模型 adapter 的第一个真实实现、流式 SSE、Markdown 展示、停止、复制、重新生成。

**前置条件**：先选定并验证一家 LLM API；确认 API Key、模型名、调用格式、流式接口、成本与网络可用性。供应商未选定时，使用 mock provider 开发 UI/API，不能假装真实模型已连接。

**验收**：两轮以上聊天能保持上下文；刷新后历史存在；多个会话互不串线；模型报错时前端可见友好错误；停止生成后消息状态正确。

**学习**：REST、SSE、异步生成器、SQLAlchemy、事务、消息角色与上下文窗口、超时和异常归一化。

## 阶段 2：文件上传与轻量 RAG

**实现**：上传与私有存储、PDF/DOCX/TXT/MD/代码文本解析、切块、关键词检索、文件问答、文件错误状态。

**验收**：上传支持的文件后能查看状态；问题可召回相关片段；回答附文件来源线索；错误格式和超限文件被拒绝；用户不能读取别人的文件 ID。

**学习**：multipart、MIME/扩展名校验、文件路径安全、解析器适配、分块、检索与 RAG、SQL 索引。

## 阶段 3：联网搜索与来源展示

**实现**：统一 `SearchProvider`、结果清洗、来源事件、自动/关闭搜索选项、搜索失败降级。

**前置条件**：选择真实搜索服务并配置密钥/额度，或确认采用可维护的自托管方案。

**验收**：启用后能返回真实来源链接；答案与来源在 UI 中可辨识；服务未配置或不可用时明确提示，不伪造来源。

**学习**：第三方 API、来源可追溯、提示注入风险、超时/重试/速率限制。

## 阶段 4：图片理解、创作模式与长期记忆

**实现**：视觉输入适配、创作模式提示词模板、记忆开关、提炼、列表/编辑/删除、相关记忆注入。

**前置条件**：所选模型或服务确认支持视觉输入；记忆提炼需要模型额外请求时，要限制调用频率和 token 以控制成本。

**验收**：视觉功能在不支持时显示不可用；创作模式提示词确实不同；记忆默认关闭，开启后才保存；关闭后停止注入/新增；删除后不再被召回。

**学习**：多模态消息格式、提示词模板、数据生命周期、隐私与最小化存储、模型调用成本。

## 阶段 5：基础 Agent 工具

**实现**：工具注册表、参数 schema 校验、计算器、文档检索、搜索工具、工具状态 UI、调用步数/超时限制、工具日志。

**前置条件**：选定模型的 tool calling 能力得到真实验证；不支持时，先评估结构化输出替代方案。

**验收**：模型能够按工具 schema 请求调用；工具结果能回给模型；非法参数、超时、工具异常能安全结束；不得执行任意 shell 或上传代码。

**学习**：Agent 控制循环、Function/Tool Calling、JSON Schema、白名单、最小权限、失败处理。

## 阶段 6：部署准备与公开访问

**实现**：Linux/云端部署、反向代理、HTTPS、持久化文件、环境变量、日志脱敏、备份、限流；在公开给他人使用前补账号认证与授权。

**验收**：重启后数据库与上传文件仍在；密钥未暴露；未登录用户无法访问别人的数据；具有基本备份与恢复说明。

**学习**：Linux、端口/进程、反向代理、环境配置、数据库备份、权限、限流与监控。

## 阶段 7：后续增强（暂缓）

- 登录、注册、账号恢复、多用户同步。
- Embedding + 向量检索，对比关键词检索效果。
- 语音、AI 图片生成/编辑、多模型切换 UI。
- 可控代码沙箱、数据分析、图表与可下载文档。
- 更复杂的任务规划与可观测 Agent。

## 每个模块的开发方式

1. 先说明该模块解决什么问题、输入输出是什么。
2. 先定 API/schema，再写最小实现。
3. 写单元测试或至少手工验收用例。
4. 本地运行验证，记录已知限制。
5. 再进入下一个模块。不要一次性生成大量看不懂的代码。
